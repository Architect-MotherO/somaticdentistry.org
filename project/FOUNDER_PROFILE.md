## 2. Core Philosophy: 3-Layer Depth Model

### The Journey: Dynamic Space → Systems Medicine → Systems Spirituality

```
물질(치아) → 전체(몸) → 의식(영혼)
= 안타카라나의 치과적 표현
= 다리 놓는 일의 물질화
```

### Level 1: Dynamic Space (동적 공간)
```yaml
Definition: "공간은 고정된 것이 아니라 끊임없이 변화하는 생명의 장"
Characteristics:
  - 물리학적 설명 가능
  - 측정 가능 (mm, 각도, 압력)
  - 일반인 이해 가능
Examples:
  - 턱 위치의 변화 (3차원)
  - 기도 공간의 확장/축소
  - 두개골의 미세한 움직임
Key Message: "동적 공간이 건강을 결정한다"
```

### Level 2: Systems Medicine
```yaml
Definition: "동적 공간의 변화가 생체 시스템 전체에 미치는 연쇄 반응"
Systems Involved:
  - 신경계 (삼차신경, CSF 흐름, 자율신경)
  - 내분비계 (Cortisol, Melatonin)
  - 면역계 (만성 염증, 사이토카인)
  - 순환계 (혈류, 산소 공급)
  - 근골격계 (자세, 근막 긴장)
Key Message: "동적 공간 → 신경-내분비-면역 통합 → 전신 건강"
```

### Level 3: Systems Spirituality
```yaml
Definition: "생체 시스템의 통합이 만들어내는 의식과 생명력의 차원"
Domains:
  - 의식 (Body awareness, 마음의 평화, Presence)
  - 에너지장 (Vital force, 기/프라나)
  - 통합적 생명력 (자기조직화, 자기치유력)
  - 영적 성장 (몸-마음-영혼 통합)
Key Message: "동적 공간의 회복 → 생체 시스템 조율 → 영적 각성"
```

### Patient Journey Example
```
1단계 (0-6개월):
  증상: "턱이 아파요"
  치료: ALF로 턱 위치 조정
  측정: OVD 3mm 증가, 기도 40% 확장

2단계 (6-18개월):
  증상: "두통이 줄고 숙면을 취해요"
  변화: 신경계 안정, 호르몬 균형
  측정: HRV 개선, Cortisol 감소

3단계 (18개월+):
  증상: "삶이 바뀌었어요"
  변화: 의식의 확장, 자기치유력 회복
  측정: 주관적 웰빙 지수, 명상 깊이
```
