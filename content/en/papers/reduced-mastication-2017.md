# Reduced Mastication Impairs Memory Function

## Citation

Reduced Mastication Impairs Memory Function. (2017). [@fukushima-nakayamaReducedMasticationImpairs2017]

## Summary

This study demonstrates that **reduced masticatory stimulation leads to impaired spatial memory and learning** through morphological changes and decreased activity in the hippocampus. Using an in vivo mouse model where juvenile mice were fed powder diet (requiring no chewing), the researchers found significant decreases in neurons, neurogenesis, neuronal activity, and BDNF expression in the hippocampus.

## Study Design

### Methodology
- **Type**: In vivo animal study (mice)
- **Model**: Juvenile mice on powder diet vs. hard diet
- **Measurements**: Hippocampal morphology, neurogenesis, neural activity, BDNF expression
- **Assessment**: Spatial memory and learning behavioral tests

### Key Variables
- **Independent**: Level of masticatory stimulation (powder vs. hard diet)
- **Dependent**: Hippocampal function, cognitive performance

## Key Findings

### Main Results

| Marker | Powder Diet | Hard Diet | Implication |
|--------|-----------|-----------|-------------|
| Hippocampal neurons | Decreased ↓ | Normal | Mastication needed for neuron maintenance |
| Neurogenesis | Decreased ↓ | Normal | Reduced new neuron formation |
| Neural activity | Decreased ↓ | Normal | Overall hippocampal function decline |
| BDNF expression | Decreased ↓ | Normal | Neurotrophic factor deficiency |
| Spatial memory | Impaired ↓ | Normal | Behavioral-level confirmation |

### Mechanistic Pathway

```
Reduced masticatory stimulation
  → Decreased trigeminal nerve input
    → Reduced hippocampal BDNF expression
      → Decreased neurogenesis
        → Impaired spatial memory & learning
```

## Somatic Dentistry Perspective

### Direct Evidence for the Tooth-Brain Connection

This study supports a core hypothesis of Somatic Dentistry — that **oral function directly influences brain health** — at the molecular level.

- **Tooth loss → reduced mastication → cognitive decline**: Mechanistically explains the epidemiological association found in Qi 2021
- **BDNF pathway**: Directly connects to Bekinschtein 2008's BDNF-memory research
- **Growth period effects**: Provides neuroscientific support for the importance of occlusal development in pediatric dentistry

### Clinical Implications

1. **New rationale for tooth preservation**: Maintaining masticatory function = protecting cognitive health
2. **ALF therapy connection**: Oral function improvement through ALF appliances may contribute to brain health
3. **Paradigm shift in geriatric dentistry**: Beyond aesthetic prosthetics toward functional rehabilitation for cognitive health

## Limitations

- Animal model → limited direct human applicability
- Powder diet changes overall food texture, not just mastication → potential confounding
- Juvenile mice → caution in generalizing to adults/elderly

## Future Research Directions

- Human longitudinal studies: masticatory function assessment + cognitive tracking
- Cognitive function changes after ALF/orthodontic treatment
- Efficacy of masticatory rehabilitation programs for cognitive protection
